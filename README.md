# AuraReview

**AuraReview** is a Business Intelligence tool built with **Python** and **Flask** for analyzing product reviews in e-commerce platforms. It helps businesses gain insights from customer feedback to improve products, enhance customer satisfaction, and support data-driven decisions.

---

## 🧠 Key Features

- 🔍 Sentiment analysis of customer reviews (positive, negative, neutral)
- 🧼 Text preprocessing and cleaning for accurate analysis

---

## ⚙️ Requirements

- **Python**: 3.13.5  
- Required dependencies listed in `requirements.txt`

---

## 🚀 Installation & Usage

1. **Clone the repository**
   ```bash
   git clone https://github.com/MohamedAgdid/AuraReview.git
   cd AuraReview

2. **Install dependencies**

 ```bash
pip install -r requirements.txt
```

3. **Run the Flask application**

```bash
python app.py
```

4. **Access the web dashboard**
Open your browser and go to:
http://localhost:5000
